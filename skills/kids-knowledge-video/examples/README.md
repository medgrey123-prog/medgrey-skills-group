| narration.photosynthesis.json | 同上，旁白原稿 |
| timings.photosynthesis.json | 合成后的逐字时间（示例） |
| sfx_plan.photosynthesis.json | 音效时间表 |
| knowledge-point.anger.json | 情绪《生气的时候怎么办》 |
| narration.anger.json | 同上 |
| timings.anger.json | 同上 |
| sfx_plan.anger.json | 同上 |
