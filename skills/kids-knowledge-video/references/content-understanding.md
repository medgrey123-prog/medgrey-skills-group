# 对内容的理解：把知识点写成 30 秒儿童短视频

这是本流程最重要的一步。画面再精致，如果只是把课文读一遍，片子就是失败的。

目标观众是 **大班到六年级**。他们能跟上具体的形象，跟不上抽象定义。一集只让他们带走一件事。

## 方法

1. **只留一个核心观念。** 先写下「看完后孩子能用自己的话说出什么」。说不消就还没想清楚。光合作用不要同时讲叶绿素、气孔和能量公式；情绪课不要同时讲生气、分享和道歉。
2. **开头 3 秒用问句钩住。** 问的是孩子身边能看见或能感觉到的事：「树叶为什么是绿色的呢？」「你有没有生过气呀？」不要以「今天我们来学习……」开头。
3. **给一个能画出来的比喻。** 叶绿素是「叶子里的小帮手」，生气是「身体里冒出了一团火」。比喻要贯穿整集，后面的机制和办法都顺着它走。
4. **用三步结构，不要五步、七步。**
   - 科学：提问 → 机制（它怎么做到的）→ 所以才这样（以及这件事还有什么用）。
   - 情绪 / 社交：先接纳这种感受 → 给出三步能做的办法 → 闪卡复习。
5. **结尾三张闪卡。** 每张一个词，加上一句很短的解释。这是给「复习本」用的，也是片子的收束。
6. **时长跟旁白走。** 先写旁白，合成后再决定画面长度。目标约 30 秒；片尾闪卡大约再留 4–5 秒。句与句之间要有空隙，让画面和音效喘口气。超时就删句子，不要加速念。
7. **情绪主题的底线。** 先承认感受（「生气不是坏事，每个人都会生气」），再教办法。不要羞辱、不要说「不许生气」「好孩子不哭」。给孩子可以做的动作：停一停、深呼吸、说出来。
8. **语言。** 短句，口语，少用书面词。必须出现的术语，紧跟着用比喻或动作解释。关键字在旁白里用 `[[cue名]]` 标出，方便画面和音效对齐。

## 旁白文件

`L/narration.json` 形状如下：

```json
{
  "voice": {"engine": "edge-tts", "id": "zh-CN-XiaoxiaoNeural", "rate": "-5%", "pitch": "+0Hz"},
  "beats": [
    {"id": "B01", "narration": "小朋友，树叶为什么是[[green]]绿色的呢？", "gap": 0.35}
  ]
}
```

- 默认音色用 `zh-CN-XiaoxiaoNeural`（更暖）。科学试片曾用 Xiaoyi，后来改成 Xiaoxiao。
- `[[cue]]` 写在要触发画面的词前面，标记本身不会被读出来。
- 需要把节奏拉开时（例如数「一、二、三、四、五」），把每个字做成单独的 beat，并给更大的 `gap`。

`scripts/tts_edge.py` 会写出 `L/build/timings.json`：每句有 `start`、`end`、逐字 `chars[]`，以及每个 cue 的时间。动画里用这些时间触发，而不是写死秒数。

## 成例一：科学《叶子为什么是绿的》（光之剧场，约 31.5 秒）

**核心观念：** 叶子看起来是绿的，因为绿光没被吃掉，被弹回了我们的眼睛。

**比喻：** 叶子里住着许多叫叶绿素的小帮手；它们爱吃红光和蓝光，把绿光推回来。

| 句 | 旁白 | 画面 | 关键 cue |
|---|---|---|---|
| B01 | 小朋友，树叶为什么是绿色的呢？ | 暗空间里一片叶子亮起来，大标题 | `green` |
| B02 | 白白的阳光里，其实藏着彩虹的好多颜色。 | 白光射入三棱镜，展开光谱 | `rainbow` |
| B03 | 叶子里住着好多小帮手，叫叶绿素。 | 镜头进到叶肉，叶绿体点亮 | `chl` |
| B04 | 它们最爱吸收红光和蓝光。 | 红光、蓝光被吸进细胞 | `red` `blue` |
| B05 | 绿光吸收得最少，被叶子弹了回来，跑进我们的眼睛。 | 绿光弹开，飞向一只眼睛 | `bounce` `eye` |
| B06 | 所以，我们看到的叶子，就是绿色的！ | 叶子绽开，回到绿色全貌 | `green` |
| B07 | 吸收的阳光，帮叶子做出养料，大树就一天天长高啦。 | 养料顺着树干走，树往上长 | `food` `grow` |
| 片尾 | （无新旁白） | 三张闪卡：叶绿素 / 阳光 / 养料，总结句 | 约 26.6 s 后 |

闪卡总结句：「红光蓝光被吃掉，绿光被叶子弹回来。」

完整旁白见 `examples/narration.photosynthesis.json`。成片旁白约 26.6 秒，加上闪卡约 31.5 秒。

## 成例二：情绪《生气的时候怎么办》（水彩绘本，约 33 秒）

**核心观念：** 生气可以先停一停、深呼吸、再说出来；生气不是坏事。

**比喻：** 生气时身体里会冒出一团火。火可以变小，但不需要假装它不存在。

| 句 | 旁白 | 画面 | 关键 cue |
|---|---|---|---|
| B01 | 小朋友，你有没有生过气呀？ | 翻开绘本，手写标题 | `hook` |
| B02 | 生气的时候，脸会发烫，拳头会握紧，心怦怦跳得好快， | 小孩特写，铅笔标出身体信号 | `face` `fist` `heart` |
| B03 | 就像身体里，冒出了一团火。 | 胸口升起火苗 | `flame` |
| B04 | 其实，生气不是坏事，每个人都会生气。 | 手写安抚句，火苗还在但不指责 | `ok` |
| B05 | 先停一停， | 画出「停一停」 | `stop` |
| B06 + N1–N5 | 再慢慢深呼吸，一，二，三，四，五。 | 蓝色水彩铺开，数数，节奏放慢 | `breath` |
| B07 | 火苗慢慢变小了。 | 火苗被吹小 | `small` |
| B08 | 然后，说出感受：我很生气，因为…… | 对话框出现，逐字写出 | `say` `quote` |
| B09 | 记住：停一停，深呼吸，说出来！ | 翻页到三张闪卡 | `c1` `c2` `c3` |

闪卡：停一停 / 深呼吸 / 说出来。结尾再落一句：「生气不是坏事，学会让心里的火苗慢慢变小。」

数数做成 5 条独立旁白，每条 gap 0.32 秒，呼吸才有时间。完整旁白见 `examples/narration.anger.json`。

这一版成片约 33 秒，比目标稍长，属于已知问题。以后同类主题应再收一句，或把闪卡压紧。

## 写分镜时顺便想音效

每个 cue 都应能配上一种「听得见的动作」：光撞上三棱镜、叶子绽开、铅笔划线、翻页、火苗变小、闪卡翻转。分镜写完，就可以直接列 `sfx_plan.json`。不要等画面渲完再临时找音效，对不齐。
